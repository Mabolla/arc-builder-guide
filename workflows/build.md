# Build Workflow

1. Read the project brief and `ARC_BUILDER_AI_GUIDE.md`.
2. Inspect the existing repository before changing anything.
3. Identify required Arc/Circle primitives and verify current documentation.
4. Write or update the project plan and file structure.
5. Implement the smallest end-to-end MVP.
6. Keep configuration and secrets out of source control.
7. Run available build, typecheck, lint, and test commands.
8. Fix actual errors and re-run checks.
9. Record meaningful decisions and reusable lessons.

## Definition of Done

- Core user flow is implemented.
- Required checks pass.
- Arc-specific assumptions are verified.
- No secrets are committed.
- Verification evidence is recorded.
