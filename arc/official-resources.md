This file is a navigation index, not a cache of mutable protocol facts.

## Verification rule

Before implementing or deploying an Arc project, re-open the relevant official documentation and confirm current network identifiers, RPC/explorer information, contract addresses, supported SDK capabilities, and supported chains. Do not treat this index as authoritative for values that can change.
