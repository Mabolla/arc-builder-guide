# Lessons Index

This directory contains reusable lessons extracted from real Builder projects.

## Lesson Format

Each lesson should answer:

1. What were we trying to do?
2. What happened?
3. What was the root cause?
4. What fixed it?
5. How do we prevent the same problem?
6. Is the lesson reusable across projects?

## Rule

Do not turn guesses into lessons. A lesson should be supported by project evidence, an authoritative source, or a clearly documented experiment.
