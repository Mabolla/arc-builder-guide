# Project Case Studies

This directory records how the Builder system is applied to real projects.

Each case study should document:

- the project goal and user problem;
- the ecosystem fit and relevant official primitives;
- the implemented milestone versus future scope;
- architecture and important decisions;
- verification evidence;
- known limitations and risks;
- lessons promoted back into the shared Builder system.

## Current case studies

- `arc-paylink/` — Arc Testnet USDC payment-link MVP.
- `arc-escrow/` — Arc testnet escrow/refund sample and its Builder lessons.

Case studies should distinguish original work from upstream samples, forks, or inherited code.
